# 朋友里藏着火箭队？这盒想玩

宝可梦十一月的新桌游，这个题目就有点想拉朋友来一局。

《お前、もしかしてロケット団？》，大概就是“你该不会是火箭队吧？”一边打宝可梦对战，一边猜谁和自己同一边。

官方信息是4～6人、10岁以上、30分钟起，¥2,200。听起来适合约朋友的时候拿出来，但我还没实际玩过，不能先替它盖章“聚会必买”。

11月12日发售，销售渠道包括宝可梦中心、官网和部分玩具、家电卖场。日文规则也要考虑进去，送人前先看看对方能不能一起读规则。

照片放了官方包装和演示画面，演示不是我的试玩记录。你朋友里谁最像能装成好人的火箭队？
